# cad-f1-pencil-holder
For this project I created a <ins>F1 pencil holder</ins> on OnShape and I 3D printed it. I made it *inspired* by the **soft compound tire** that is used by Formula 1 cars. I created this project so I can personally use this pencil holder, because I *really* like F1 and I like the design that I created myself. It took a while to make. I had to learn some new things like wrapping text on cylinders.
